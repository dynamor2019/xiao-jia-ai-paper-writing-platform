# 0.1.11：论文工作流与上下文成本保护

## 本版内容

- 将论文工作流中的上下文恢复、缓存前缀稳定化、有限重试和产物治理统一纳入运行保护。
- 增加对长上下文、重复注入和无效中间产物的成本控制，避免无实质进展时持续生成内容。
- 保留模型访问、中转站配置、API 密钥和系统网络设置，不随版本更新覆盖用户配置。
- Release 构建改为使用当前版本号和对应发布说明，不再复用旧版本说明。

## 安装方式

下载 `XiaoJiaAI-Source-v0.1.11.zip`，解压后运行 `setup-dsh.bat`，完成后运行根目录的一键启动 BAT。

发布包只包含项目文件、公开技能、配置模板与依赖清单，不包含 `node_modules`、Electron 二进制、下载缓存、个人论文或密钥。依赖由安装脚本在用户电脑联网下载。

## 边界说明

本版不改变模型 API、中转站 URL、协议、TLS、密钥或系统网络配置；软件测试仅验证安装、更新和流程逻辑，不代表论文通过科学审查或获得投稿认证。
