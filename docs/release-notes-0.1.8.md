# 0.1.8：项目精简与受保护更新

## 为什么修改

- 本地旧内核审查与回滚快照重复占用空间，用户下载无需携带开发机环境。
- 缓存前缀反复变化、上下文恢复重复注入和短暂连接中断会增加成本或打断任务；本版汇总已验证的上下文稳定化、有限重试及内核兼容修复，不承诺中转站缓存百分比。
- 平台需要可见的新版本通知，且不能在论文执行中替换运行文件。

## 安装方式

只下载 `XiaoJiaAI-Source-v0.1.8.zip`，解压后运行 `setup-dsh.bat`，完成后运行根目录的启动 BAT。

发布包只包含项目文件、公开技能、配置模板与依赖清单；不包含 node_modules、Electron 二进制、Python 环境、下载缓存、个人论文或密钥。依赖说明见 requirements.txt，Node.js 精确依赖使用 package.json/package-lock.json，setup 在用户电脑联网下载。建议完整安装 Node.js 24 LTS。

## 自动更新

启动后检查本仓库正式 Release，之后每六小时检查一次；侧栏显示当前版本和新版本。默认自动下载源码更新包，校验 ZIP 与每个文件 SHA256，下次关闭平台后重新启动时安装；当前论文任务不中断。断网或下载失败继续使用原版。

更新事务保存被替换文件并支持回滚。依赖版本变化、本地未提交修改或模型受保护代码变化需要手动安装和审查，不静默覆盖。用户数据、API 密钥、模型中转站设置和系统网络不属于自动更新范围。可通过环境变量 `DSH_AUTO_UPDATE=false` 关闭自动下载，仍可查看新版提示。

## 空间与验证边界

开发机两份旧内核快照已在项目外压缩归档并逐文件校验，净释放约 1.22 GiB；个人数据与不同内容的历史证据保留。运行时依赖由各用户自行安装，不能把全局 npm 下载缓存当作所有项目可互换的 node_modules。

软件测试验证安装、回滚、模型保护与流程逻辑；不代表任何论文通过科学审查或获得投稿认证。
