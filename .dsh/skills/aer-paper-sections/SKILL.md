# AER Paper Sections — 各节写作规范

> **先有数字，后有文字。** 实证结果稳定后才开始引言和正文；引言是对已存在论文的总结，不是对未来论文的承诺。

---

## 章节架构（标准实证论文）

```
[无标题引言段落]       ← 无 "Introduction" 标题，AER 强制规范
I.   背景 / 制度背景
II.  数据
III. 实证策略
IV.  结果
V.   机制 / 异质性
VI.  结论
参考文献
表格（按序）
图形（按序）
附录
```

*AER:Insights 压缩为：数据与设计 → 结果 → 讨论*  
*理论论文在数据前插入：模型*  
**每个术语、数据集、设计特征必须在首次出现时定义，不得假设读者已知。**

## 引言 — Keith Head 五段公式

引言是编辑决定是否送审的唯一依据，桌面拒稿通常发生在第 1–3 页。

### § 1 — Hook（1–2 段）

四种开场方式，选一种：

| 类型 | 示例句式 |
|---|---|
| **Y 很重要** | "制造业就业占 GDP 的 X%，但其对工资的影响尚无设计可信的估计。" |
| **Y 很奇怪** | "教育回报在同一国家内跨地区差异高达 3 倍，标准人力资本理论无法解释。" |
| **Y 有争议** | "关于 X 对 Y 的效应，A 文献认为正，B 文献认为负。" |
| **Y 规模巨大** | 锚定一个数字，2–3 句。|

**禁止开场方式**：  
× "经济学家长期以来关注……"  
× "文献缺少关于 X 的模型……"  
× 可爱引言（名人名言）  
× "随着 X 的不断发展……"

### § 2 — 研究问题（1 段）

```
本文[估计/记录/分析] [X 对 Y 的因果效应 / Y 对冲击 S 的响应]，
识别依据 [识别策略]，使用 [数据来源]，
发现 [主要结果，含数量和符号]。
```

**主要结果必须在第 2 段给出**，不得留到第 4 节。  
句子主语用"本文"（This paper），不用"我们"（We）。

### § 3 — 识别（1–2 段）

**这是桌面拒稿的高发段落**。

- 一句话命名识别策略：识别 Y 的关键变异来自 ___。
- 1–2 段解释：什么变异驱动识别 + 为什么平行趋势 / 排他性 / 连续性假设在本情境下可信。
- 引用具体数据特征为假设背书（不是空洞的"控制了固定效应"）。

理论论文：命名模型机制和核心参数化，说明什么是可处理的，给出的比较静态是什么。

### § 4 — 前因文献 + 价值贡献（2–3 段）

**本段是审稿人引用报告的来源**，通常是引言中最重要的一段。

结构：前因 → **however** → 本文贡献

- 只讨论 3–6 篇最近的文献；多了显得不精准。
- 每篇文献说明：做了什么 + **留下了什么未解决**。
- 然后提出**恰好三条贡献**（不多不少），每条贡献仅在参照这些前因文献后才有意义。

**禁止表达**：  
× "据我们所知，这是第一篇……"（无法核实，通常也是假的）  
× "我们为 X 文献做出贡献"（说什么贡献，不说"做出贡献"这个动作）  
× 贡献列表超过四条

### § 5 — 路径图（1 短段）

"第 I 节描述……第 II 节介绍……第 III 节……"

*AER:Insights 短文可省略路径图。*

## 摘要 — 100 词规范

AER 摘要**强制 ≤ 100 词**，超过直接退回。

| 功能 | 句数 | 词预算 |
|---|---|---|
| 研究问题与情境 | 1 | 15–20 |
| 数据与识别策略 | 1 | 15–20 |
| **主要结果（含数量）** | 1–2 | **30–40** |
| 含义 | 1 | 10–15 |

**词预算分配给结果最多**。动机性摘要（大量背景、少量结果）是错误写法。

**摘要模板**：
```
[情境与研究问题——1句]。
[数据与识别——1句]。
[主要定量结果——1–2句]。
[含义——1句（可省略以节省字数）]。
```

超过 100 词的压缩流程：
1. 删除所有不改变意思的形容词
2. 用分号替换从句
3. 删除含义句
4. 把 "we find that X" 改为主动式 "X raises Y by Z%"
5. 数字按一个词计

## § I — 背景 / 制度背景

- **只保留**识别变异所在的制度细节和使假设可信的事实，多余的历史一律删除或移入引言前因段。
- **谁被处理、何时、按什么规则、谁决定的**——这四点必须答清楚。
- 每个制度性主张引用**一手来源**（法律文件、行政报告），不用二手经济学论文。
- 篇幅：1.5–3 排版页；超出通常是隐藏的文献综述，删掉或移到引言。

---

## § II — 数据

**审稿人逐行比对数据节与复现包**，任何不一致都是拒稿理由。

四个必须包含的块：

**来源**：每个数据集 → 名称、生产方、访问方式、年份、观测单位、引用。

**样本构建漏斗**（"脚注 4 规范"，直接粘入脚注）：
```
原始数据                N = xxx,xxx
1. 删除缺失主结局        N = xxx,xxx
2. 限年龄 18–65          N = xxx,xxx
3. 保留目标行业          N = xxx,xxx
最终分析样本             N = xxx,xxx
```
任何步骤删除 >5% 须在正文解释；所有 N 必须与复现包精确匹配。

**变量定义**：处理变量和结局变量用正文精确定义（含单位）。测量误差、编码、缩尾、平减指数在此处理，不在附录。

**描述统计叙述**：叙述 Table 1，不是重读它。2–4 个设计相关事实：样本代表性、处理组/控制组可比性、对规格选择有意义的分布特征。

## § III — 实证策略

**四个必须按序出现的组件**：

### 1. 估计量（先于方程）

> "本文关注 [处理变量] 对 [结局] 在 [总体] 的 [ATT / ATE / LATE]，在 [时间跨度] 内。"

若设计只能识别局部效应（LATE、断点处效应、ATT for switchers），在此说明，不要在结论的局限段才提。

### 2. 估计方程

```latex
Y_{ict} = \beta\, D_{ct} + \alpha_c + \gamma_t + X_{ict}'\delta + \varepsilon_{ict}
```

- **定义每个符号**（方程后紧跟一句话，含下标含义）
- 标注哪个系数是关注对象，哪些变异识别它
- 现代 DID：写 ATT(g,t) 估计量和聚合方式，不要假装是 TWFE

### 3. 识别假设

**状语**陈述假设 + **威胁** + **证据预告**：
> "假设：控制组反映了处理组在不被处理情况下的潜在结局轨迹。主要威胁是 [X]。我们通过 [事件研究图 / 安慰剂] 检验这一假设，结果见图 2。"

### 4. 推断

一段：聚类层级 + 选择理由 + 聚类数 + 是否需要 wild bootstrap（<50 个聚类）或 AR 置信区间（弱工具）。

**不能只在表格注释里说推断方式**，必须在正文段落明确。

## § IV — 结果：narration discipline

**每段 = 一个主张，不是一张表格。**

标准结构（每段三要素）：

```
1. 经济发现（首句）：
   "该改革将工资提高了 4.2 个对数点（表 3，列 4）。"
   ← 不得写："表 3 展示了结果。"

2. 证据：
   系数来自哪里，在各规格中如何变动（M1→M6 系数稳定性）。

3. 解释：
   转换为经济单位，与文献或政策基准对比。
```

### 系数转换规范（必须执行，不能省略）

| 结局形式 | β 含义 | 精确转换 |
|---|---|---|
| log(Y)，二值 D | 对数点 | 若 \|β\| > 0.10：100×(e^β − 1)% |
| log(Y)，log(X) | 弹性 | β% per 1% of X |
| 水平 Y，二值 D | Y 的 β 个单位 | 100×β / mean(Y) |
| 比例/率 Y | β×100 **百分点** | 别混淆 pp 和 % |

例：β = 0.31 → 转换为 36%（不是 31%），必须写出；β = 0.04 on a rate → 4 pp（不是 4%）。

**三重基准化**（每个主要系数都要做）：
1. 相对于样本均值 / SD
2. 相对于文献中已知效应量
3. 相对于政策相关阈值（如适用）

### 稳健性指向

结果节**引用**稳健性，不包含稳健性：

> "结果在聚类方式、样本范围、结局定义和估计器各维度均保持稳定；附录 B 报告了完整的稳健性检验矩阵。最重要的一项稳健性见列 (5)：……"

## § V — 机制 / 异质性

**按候选解释组织，不是按表格组织。**

```
1. 命名 2–3 个与主结果一致的渠道（包括你要排除的）
2. 对偏好渠道：
   - 理论预测的异质性（效应在哪里应该更大？）
   - 验证性辅助结局（"若渠道是技能偏向采用，效应应集中在服务业——确实如此，表 5"）
3. 对每个替代解释：
   - 最有力的版本（steelman）
   - 针对性证据（为何不支持）
4. 校准语言：
   ✓ "与 [渠道] 一致"
   ✓ "为……提供了证据"
   × "证明了机制"（机制证据是一致性证据，不是识别证据）
```

异质性只报告**理论预测的**，不报告数据挖掘发现的；挖掘结果若报告，必须明确标注为"探索性"。

---

## § VI — 结论（半页到一页）

**四件事，按序，不超出：**

1. 用**新词**重述研究问题和主要数量结果（不是原文复制，`aer-consistency` 会检查重复）
2. 外部效度边界：总体、时期、政策边际、设计暗含的局部效应
3. **一条**政策或理论含义（证据支持的一步，不是三步）
4. **最多两句**具体的后续研究方向（不是"需要更多研究"）

**禁止在结论里出现**：  
× 新结果  
× 新引用  
× 结果节已经处理过的局限（别挪到这里）  
× 从摘要/引言逐字复制的段落  
× "本文的局限性是……（列举 5 条）" —— 写进结果节，校准语言即可

---

## 跨节一致性规则

- 引言的承诺（贡献、数量、证据）与正文**一一对应**，没有未兑现的承诺，也没有未预告的重要结果
- 时态：现在时报告发现；过去时描述数据收集和历史事件
- `aer-consistency` 在投稿前审计所有数字、样本量、规格标签的一致性
