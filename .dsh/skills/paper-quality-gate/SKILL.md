# Paper Quality Gate

## 完成定义

“段落已写完”“DOCX 已生成”和“论文可投稿”是三个不同状态。只有以下门禁全部 PASS，才能把任务标记为完成：

1. 引用真实性审计无未核验条目。
2. `npm run paper:validate -- <paper.md> <paper.docx>` 返回 PASS。
3. 独立科技审查对理论、方法、实验、呈现、复现和前后一致性均无 critical/major 问题。
4. 目标期刊 `submission-readiness` 清单无 BLOCKED 项。
5. `topic-discovery.md` 含可访问的联网证据，`analysis-plan.md` 已在实验前冻结。
6. `experiment-run.log` 记录成功命令、结果路径与 SHA256；`data-validation.md`、`data-validation.json` 和 `data-validation-history.tsv` 证明当前哈希已通过结构、科学/统计和独立复算三重校验。
7. 每个正文主图均有 PNG、PDF 和状态为 PASS 的 Nature 配置 `.qa.json`；报告必须含图注标题和独立图注正文，且已由图像模型读取最终 PNG 完成视觉复核，缺少任一项即不得导出终稿。
8. 图清单中每张图均有多面板理由、受影响论断和图文同步状态；`text_sync_status`、`visual_qa_status` 或总状态不是 PASS 时不得导出终稿。
9. `milestones/reproducibility/result-provenance.tsv` 覆盖正文、表格和图中的全部定量主张，来源文件哈希、筛选条件、分析脚本和输出字段均可复核且状态为 VERIFIED。
10. 数据完整性审查确认绘图脚本没有随机生成实例、手填结果数组、硬编码统计量或条件隐藏不利结果；合成/模拟数据在数据集、方法、图注和限制中均被明确标识。
11. 图号、表号及正文首次引用严格递增，文件、图注、交叉引用和 DOCX 中编号一致。
12. 第一段正文的创建时间晚于冻结方案、正式实验和三重数据 PASS；任何后续数据哈希变化均已使受影响文字回退并重新校验。

## 强制阻断项

- 公式在 DOCX 中仍显示 `$...$`、LaTeX 命令或普通文本伪公式。
- 定理缺少定义、条件、正式公式或证明不支持结论；拉格朗日、对偶、界和复杂度推导存在缺项。
- 正文引用 Table/Figure，但文件内没有真实表格或图片。
- References 后出现重复标题、目录、检查点、TODO 或续写标记。
- 数值无法追溯到数据与脚本，或统计、求解器、随机种子和实验设置不足以复核。
- 仅有合成实验却把结论外推到真实工程，且没有案例验证、敏感性、消融或明确限制。
- 先写结果后跑实验、结果数字只存在于对话/正文、实验日志失败、数据文件未验收或方案在看到结果后无记录地改动。
- 选题只凭模型常识，没有联网检索证据、研究空白比较、可行性评估或目标期刊范围核对。
- 主图未通过 `scientific_figure_guard.py`，存在字号、重叠、裁切、DPI、空白输出问题，或只生成文件而未做图像视觉复核。
- 未经必要性论证把单图扩成组合图，或改图后未同步复核图注、Results、Discussion 及受影响的摘要和结论。
- 用随机分布或汇总均值重建“实例级数据”，把模拟点描述为真实观测，或把正文/图注中的数字反向写入绘图代码。
- 在绘图脚本中硬编码 P 值、相关系数、效应量、显著性星号或结果序列，而没有机器结果字段和计算脚本的可追溯映射。
- 通过显示阈值、条件标注、坐标裁切或删除失败运行隐藏负效应、零效应和异常结果。
- 仅凭相关、回归或观察性比较使用 cause、drive、prove、confirm mechanism 等因果措辞，或图中数据与标题、图注、摘要和结论的数字不一致。
- Figure/Table 编号乱序、重复、跳号，或先出现后编号再返回较小编号。
- 把“文件可读取”“程序退出码为 0”或语言模型检查当作数据正确性的充分证据；缺少独立复算、统计审计或当前哈希 PASS 时一律阻断。
- 手工改写 CSV/JSON/TSV 结果、从正文或图注反向填数、只保留有利运行、删除失败/零效应/反例，或在发现结果后无 amendment 地修改假设与纳排规则。

## 修订循环

质量报告中的每个问题分配稳定 ID；一次只修复一个问题并更新证据位置。修复后重新执行源稿校验、独立审查、DOCX 导出后校验。不得通过降低严重级别、删除报告或改写完成提示绕过门禁。
