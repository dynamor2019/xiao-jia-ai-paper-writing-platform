# 学术文献检索与综合分析

## 触发条件
- 用户要求"查找文献"、"做文献综述"、"了解XX领域研究现状"
- 论文写作的 Stage 2（深度文献检索）
- 需要找特定主题的相关工作（Related Work）

## 检索流程

### 第一步：关键词设计
设计至少5组不同的检索关键词：
1. 核心概念词（如 "deep learning" + "medical imaging"）
2. 方法变体词（如 "neural network" / "CNN" / "transformer"）
3. 应用场景词（如 "clinical diagnosis" / "disease prediction"）
4. 综述类词（加 "survey" / "review" / "advances"）
5. 最新进展词（加年份 "2024" "2025" "2026"）

### 第二步：多轮联网检索
对每组关键词使用 web_search：
- 记录搜索结果中的高相关性论文
- 对高被引论文做 citation chaining（搜索其引用的论文和引用它的论文）
- 重点关注：近3年论文、高被引论文、顶会顶刊论文

### 第三步：知识卡片提取
对每篇入选论文，提取结构化知识卡片：
```
【论文标题】
【作者】 | 【年份】 | 【期刊/会议】
【核心方法】：一句话概括
【主要发现】：2-3条关键结果
【数据集/实验设置】：
【与本研究关系】：高度相关/一般相关/背景参考
【可引用点】：可以在论文哪些地方引用
【可信度】：高/中/低（基于期刊等级和引用数）
```

### 第四步：文献分类与综合
1. 按主题/方法对文献聚类
2. 识别不同学派/方法路线
3. 找出文献间的矛盾和分歧
4. 识别研究空白（哪些问题还没解决）
5. 按影响/可行性/相关性排序研究空白

### 第五步：生成文献综述
输出结构化的文献综述：
- 领域发展脉络
- 主要方法路线（每条路线的代表工作和优缺点）
- 当前研究热点
- 研究空白与机会
- 本研究的定位

## 质量标准
- 至少15篇高相关性论文
- 每篇都通过搜索验证真实存在
- 覆盖近3年最新进展和经典奠基工作
- 知识卡片信息完整
- 研究空白分析有深度，不是泛泛而谈

## 输出文件
- `related-work.md` — 文献综述全文
- `papers/knowledge-cards.md` — 所有知识卡片
- `papers/research-gaps.md` — 研究空白分析
