# 参考文献真实性核验工具

## 触发条件
- 论文中出现参考文献列表时
- 用户要求"检查引用是否真实"、"核实参考文献"、"有没有编造的文献"
- 生成或润色论文后，必须自动执行引用核验
- 任何包含 [1]、[2] 等引用标记或 References 章节的内容

## 核验流程

### 第一步：提取所有参考文献
从论文中提取每一条参考文献的：
- 作者姓名
- 论文标题
- 期刊/会议名称
- 发表年份
- 卷号、期号、页码（如有）
- DOI（如有）

### 第二步：逐条联网核验
对每一条引用，使用 web_search 搜索：
1. **精确搜索标题**：用论文标题加引号搜索，看是否能找到匹配结果
2. **搜索 DOI**：如果有 DOI，搜索 "DOI: 10.xxxx/xxxxx" 验证
3. **搜索作者+期刊**：搜索 "作者名 期刊名 年份" 交叉验证

### 第三步：判断真实性

**真实文献的特征：**
- 能在 Google Scholar、PubMed、IEEE Xplore、ACM DL、CNKI 等数据库找到
- DOI 可以解析到对应论文页面
- 作者、期刊、年份信息一致
- 有明确的发表记录和引用记录

**可疑/编造文献的特征：**
- 搜索标题完全找不到结果
- DOI 无法解析或指向不相关页面
- 作者名字与论文不匹配
- 期刊名称不存在或拼写错误
- 年份与期刊卷号对不上
- 内容过于"完美"但查无此文

### 第四步：输出核验报告

对每条引用标注：
- ✅ 真实：已验证存在
- ⚠️ 存疑：部分信息匹配但不完全确认
- ❌ 编造：搜索不到，高度怀疑是 AI 编造

对存疑和编造的引用，给出：
- 问题出在哪里
- 建议的真实替代文献（通过搜索找到的相关真实论文）
- 或者建议删除该引用

## 参考文献形式检查（格式规范，强制）

在真实性核验之后，必须对每条参考文献执行形式检查。发现格式问题逐条标注并修正。

### 通用检查项（所有引用样式通用）

| 检查项 | 要求 |
|--------|------|
| 作者姓名格式 | 姓在前，名缩写在后；多位作者之间分隔符统一；3人以上是否用 et al. 符合样式要求 |
| 年份格式 | 四位数字，位置符合样式要求；无多余括号或标点 |
| 论文标题 | 大小写符合样式要求（句首大写 vs 标题大小写）；末尾标点统一 |
| 期刊/会议名 | 全称或标准缩写统一；是否斜体符合样式要求 |
| 卷号期号 | 卷号、期号、页码格式统一；期号是否加括号符合样式 |
| 页码范围 | 使用正确的连接符（– 或 -）；起止页码完整 |
| DOI | 格式为 `https://doi.org/10.xxxx/xxxxx` 或 `doi: 10.xxxx/xxxxx`，全文统一 |
| URL | 仅在线资源或无DOI时使用；标注访问日期（如样式要求） |
| 标点符号 | 每条末尾标点统一；作者间、年份、标题、期刊间的分隔符统一 |
| 引用类型 | 期刊论文、会议论文、书籍、章节、预印本、网页、报告等类型标识正确 |
| 正文-列表对应 | 正文每个引用标记在参考文献列表中有对应条目；列表每条在正文中被引用 |
| 排序 | 按正文出现顺序或作者字母排序，全文统一 |

### IEEE 样式专项检查
- 作者：`A. B. Author, C. D. Author, and E. F. Author`
- 格式：`作者, "论文标题," 期刊缩写, vol. X, no. Y, pp. xxx–yyy, 年.`
- 会议：`作者, "论文标题," in Proc. 会议名, 年, pp. xxx–yyy.`
- 书籍：`作者, 书名, 版次. 出版地: 出版社, 年.`
- 期刊名使用标准缩写（如 IEEE Trans. Autom. Sci. Eng.）

### APA 样式专项检查
- 作者：`Author, A. B., Author, C. D., & Author, E. F.`
- 格式：`作者 (年). 论文标题. 期刊全称, 卷(期), xxx–yyy. https://doi.org/...`
- 期刊名和卷号斜体
- 7人以上用 et al.（第7人后）
- DOI 必须为完整 URL 格式

### Vancouver/数字样式专项检查
- 作者：`Author AB, Author CD, Author EF.`
- 格式：`作者. 论文标题. 期刊缩写. 年;卷(期):xxx–yyy.`
- 按正文引用顺序编号
- 期刊名使用 NLM 标准缩写

### Chicago 样式专项检查
- 注释-参考文献制：脚注/尾注 + 参考文献列表
- 作者：`作者, "论文标题," 期刊名 卷, no. 期 (年): xxx–yyy.`
- 参考文献列表中作者倒置，脚注中不倒置

### 常见形式错误清单（逐条排查）
- [ ] 作者姓名全拼与缩写混用
- [ ] 期刊名全称与缩写混用
- [ ] 有的有DOI有的没有（有DOI的必须统一给出）
- [ ] 页码用了半角连字符 `-` 而非 en dash `–`
- [ ] 卷号期号格式不统一（有的 vol. 有的省略）
- [ ] 末尾标点有的有句号有的没有
- [ ] 正文引用 [1] 但列表中缺第1条，或列表有条目正文未引用
- [ ] 预印本（arXiv）未标注，误标为已发表期刊论文
- [ ] 网页引用缺少访问日期
- [ ] 中文文献拼音/英文翻译格式不统一

### 形式检查输出
对每条参考文献标注：
- ✅ 格式正确
- ⚠️ 格式问题（列出具体问题：作者格式/期刊缩写/标点/DOI等）
- 🔧 已修正（给出修正后的条目）

形式检查完成后，统一修正所有问题，确保全文参考文献格式100%一致。

## 重要规则

1. **永远不要编造参考文献**。如果找不到真实文献，宁可少引用也不要编造。
2. **引用必须可追溯**。每条引用都应该能通过搜索验证其存在。
3. **核验是强制步骤**。生成任何包含参考文献的内容后，必须执行核验。
4. **如实报告**。发现编造引用时，明确告诉用户哪些是假的，不要隐瞒。
5. **提供替代方案**。对编造的引用，搜索并推荐真实的相关文献替代。

## 常用学术搜索关键词

- `site:scholar.google.com "论文标题"`
- `"论文标题" author`
- `DOI: 10.xxxx/xxxxx`
- `作者名 期刊名 论文标题`
- `论文标题 filetype:pdf`
