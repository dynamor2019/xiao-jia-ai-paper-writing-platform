# 学术论文同行评审

## 触发条件
- 用户要求"评审这篇论文"、"帮我审稿"、"检查论文问题"
- 论文写作的 Stage 5（三视角同行评审）
- 投稿前的质量检查

## 评审流程

### 第一步：通读全文
完整阅读论文，理解：
- 研究问题是什么
- 用了什么方法
- 得到了什么结果
- 核心贡献声称是什么

### 第二步：三视角独立评审

#### 视角一：方法论严谨性（Reviewer 1）
审查维度：
1. **研究设计** — 研究问题是否清晰？假设是否合理？
2. **实验设计** — 实验是否可复现？对照组是否合理？
3. **统计方法** — 统计检验是否正确？效应量是否报告？
4. **内部效度** — 是否有混淆变量？因果推断是否合理？
5. **威胁分析** — 是否讨论了有效性威胁？
6. **可复现性** — 代码/数据是否可用？参数是否完整？

每项1-10分，给出具体问题和修改建议。

#### 视角二：创新性与贡献（Reviewer 2）
审查维度：
1. **新颖性** — 与现有工作的区别是什么？是否有实质性创新？
2. **技术贡献** — 方法/技术上的贡献是什么？
3. **研究意义** — 对领域的影响和价值？
4. **与现有工作区分** — Related Work 是否充分？是否清楚定位？
5. **实验充分性** — 实验是否足以支撑声称的贡献？

每项1-10分，给出具体问题和修改建议。

#### 视角三：表达与呈现（Reviewer 3）
审查维度：
1. **写作质量** — 语言是否清晰？学术表达是否规范？
2. **结构逻辑** — 章节组织是否合理？论证是否连贯？
3. **图表质量** — 图表是否清晰？编号是否正确？说明是否充分？
4. **引用规范** — 引用格式是否统一？是否有遗漏？
5. **可读性** — 目标读者能否理解？术语是否定义？

每项1-10分，给出具体问题和修改建议。

### 第三步：论文-证据一致性检查
对论文中的每个关键声称：
1. 找到声称的位置
2. 检查是否有对应的数据/引用支撑
3. 标注：✅有支撑 / ⚠️支撑不足 / ❌无支撑
4. 对无支撑的声称，建议删除或补充证据

### 第四步：综合评审决策
综合三个视角的评分：
- **≥80分** — Accept（接收）
- **65-79分** — Minor Revision（小修）
- **50-64分** — Major Revision（大修）
- **<50分** — Reject（拒绝）

给出：
- 综合评分
- 主要优点（3点）
- 主要问题（按严重程度排序）
- 修改优先级（必须改/建议改/可选改）

## 评审原则
1. **建设性** — 指出问题的同时给出具体修改建议
2. **基于证据** — 所有批评都要精确到段落/句子，不使用"应该""看起来"
3. **公平客观** — 不因个人偏好否定工作，区分"不够好"和"有错误"
4. **具体可操作** — 修改建议要明确，让作者知道怎么改

- `reviews/reviewer-2-novelty.md`
- `reviews/reviewer-3-presentation.md`
- `reviews/summary.md` — 综合评审报告
