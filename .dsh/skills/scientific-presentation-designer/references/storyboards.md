# 科技汇报叙事结构

## 学术会议报告

使用 `问题冲突 → 现有缺口 → 方法直觉 → 方法结构 → 实验可信度 → 主要发现 → 为什么成立 → 限制与意义`。开场两页内说明研究问题与价值；方法细节只保留理解结果所需部分。

## 学位答辩

使用 `研究背景 → 明确问题 → 文献定位 → 研究问题/假设 → 方法与数据 → 多组结果 → 稳健性 → 贡献 → 局限与未来工作`。每项贡献都回指一个研究问题和对应证据。

## 项目或基金汇报

使用 `任务目标 → 场景痛点 → 技术路线 → 当前进展 → 可核验证据 → 风险与对策 → 下一阶段 → 资源/决策请求`。进展页区分已完成、验证中和计划，不把计划写成结果。

## 页面信息任务

每页必须属于一种任务：提出问题、解释机制、呈现证据、比较方案、说明流程、界定限制或推动决策。无法归类的页面通常应删除或并入相邻页面。

页面标题应能独立形成一条连贯摘要。只阅读全部标题时，听众仍应理解研究问题、方法、主要发现和结论。
