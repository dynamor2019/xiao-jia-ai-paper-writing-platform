# Pre-Submission Review — 投稿前审计

> **最便宜的审稿报告是投稿前自己写的那份——前提是它和真实审稿人一样严苛。**

本 skill 分两阶段运行。第一阶段检查机械一致性（数字、引用、交叉引用），第二阶段模拟编辑桌面审查和三位独立审稿人的评审报告。两个阶段必须都通过才能提交。

---

## 第一阶段 — 一致性审计（7 项）

每项结果为 PASS / FAIL，FAIL 是投稿阻断项。

### Audit 1 — 标题数字登记表

建立数字登记表，每行对应一个在正文中出现超过一次的数字：

```
NUMBER          SOURCE        ABSTRACT  INTRO  RESULTS  CONCL  MATCH
4.2 log pts     Tab 3 col 4   yes       yes    yes      yes    OK
SE 1.1          Tab 3 col 4   yes       no     yes      no     OK
N = 37,824      Tab 1         no        no     yes      no     OK
```

规则：
- 每个引用的估计值与表格**精确到最后一位数字**匹配（不得重新四舍五入）
- 摘要、引言、结论引用**同一规格**的系数，不得摘要引列(3)、引言引列(5)
- 外部来源数字（引言 hook 用的）首次出现带引用，且全文数值一致

### Audit 2 — 样本量一致性

- 数据节的样本漏斗算术正确：逐行删除数量加总 = 最终样本量
- 主结果表的 N 与 Table 1 匹配（同规格下）；所有偏差须在表格注释和正文中解释
- 异质性子样本 N 之和 = 全样本 N（扣除明确排除项）

### Audit 3 — 单位与转换

对照转换表检查每个系数在正文中的叙述：

| 结局形式 | 正确用词 | 常见错误 |
|---|---|---|
| log(Y)，\|β\| ≤ 0.10 | β×100 **log-points ≈ %** | 写成"百分点" |
| log(Y)，\|β\| > 0.10 | 100×(e^β − 1)% | 直接写 β×100% |
| 比例结局 | β×100 **百分点（pp）** | 和"百分比"混用 |
| 货币 | 说明基准年和平减指数 | 没有写单位年份 |

β = 0.031 on a rate → "3.1 个百分点"，不是"3.1%"。  
β = 0.31 on log(Y) → 36%，不是 31%（e^0.31 − 1 ≈ 0.363）。

### Audit 4 — 显著性星号与标准误

- 每个加星系数：`|β/se|` 与表格注释的星号阈值一致（典型：1.65/1.96/2.58）
- 正文"在 X% 水平显著"与表格星号 + CI 三方一致
- "无效应"必须报告 CI，不能只靠星号缺失

### Audit 5 — 交叉引用完整性

- 所有 `\ref{}` / `\autoref{}` 可解析（PDF 中无 `??`）
- 每张表、每张图在正文中至少被引用一次，且按顺序
- 章节引用在 R&R 修订后编号未因重排而错误

### Audit 6 — 引用双向匹配

- 每个 `\cite{key}` 在 `.bib` 中有对应条目
- 每个 `.bib` 条目至少被引用一次（LaTeX 编译零 warning）
- 引用核验台账 `citation-ledger.tsv` 全部行状态 = `yes`（由 `citation-integrity` skill 维护）

### Audit 7 — 主张-证据映射

对摘要、引言、结论中的每个**实证主张**：

```
CLAIM                                          EVIDENCE          STATUS
"将 90/10 比率提高 4.2 个对数点"               Tab 3 c4          OK
"效应集中在贸易品服务业"                        Fig 3 / Tab 4     OK
"与技能偏向采用一致"                            § V               OK（一致性主张）
```

- 因果主张 → 指向设计证据（DID/IV 等）
- 机制主张 → 措辞为"与……一致"，不是"证明了机制"
- 无证据指向的主张 → 删除或降级措辞

## 第二阶段 — 模拟审稿

**规则：模拟审稿人的工作是拒稿，不是鼓励。** 只有两轮连续达到 major R&R 或更好才可提交。

### 桌面审查（编辑 10 分钟）

编辑只读前 3 页 + 主表 + 参考文献。评估三件事：

**贡献扫描**：读完第 3 页后，能否用一句话说出本文贡献？非本领域经济学家关心吗？

**设计扫描**：前 1–2 页是否命名了识别策略？是否是现代设计（无 `causal-inference` 红线）？

**工艺扫描**：表格是否 booktabs 格式，摘要是否 ≤100 词，正文是否有 AI 写作标志词。

```
桌面决定: <拒稿 | 送审>
编辑信: <编辑会实际发出的信的文字>
```

校准：`causal-inference` 红线触发任意一条 → 桌面拒稿，写信后停止，修改后重跑。

### 三位模拟审稿人

**每位审稿人独立撰写报告，不互相继承发现**。

#### 审稿人 1 — 识别专家

**阅读顺序**：实证策略 → 数据 → 稳健性附录  
**先验**："设计是有问题的，直到被证明正确。"

攻击：
- 识别假设在本情境的具体可信度
- `causal-inference` 检验清单缺失的诊断项
- 推断层级与变异来源不匹配
- 估计量-总体不一致（"谁的效应？"）
- 设计无法排除的替代故事
- 至少从表格重新推导一个量值，检查是否与正文一致

#### 审稿人 2 — 领域专家

**阅读顺序**：引言 → 前因文献段 → 结果（对照文献）  
**先验**："我们可能已经知道这个了。"

攻击：
- 新颖性：针对工作论文前沿（不只是已发表文献）；命名最近的具体论文
- 量值与文献的可比性
- 机制证据是否区分了主渠道和明显替代渠道
- 领域内部人士会注意到的制度性错误
- 审稿人 2 可能就是前因文献的作者——特别检查引用是否准确表达了那些论文的发现

#### 审稿人 3 — 通才（非本子领域）

**阅读顺序**：线性通读，模拟编委成员  
**先验**："为什么我要关心这个？"

攻击：
- AER 跨子领域兴趣（劳动论文是否对宏观/IO/公共有意义？）
- 前 3 页是否自成一体
- 系数从未被转换为经济意义（`aer-paper-sections` narration discipline）
- 图表过多 / 无序
- 结论超出证据范围
- 外部效度未处理

### 报告格式（每位审稿人）

```
摘要: <2–3句——审稿人理解到的论文>

主要意见:
[n]. [引用原文或表格/图形编号]
     问题: ...
     需要什么证据能解决: ...

次要意见:
[m]. [位置] [问题] [建议]

推荐: <拒稿 | 大修 | 小修>
```

规则：
- **每条主要意见必须锚定**：引用原文或指向具体表格/图形
- **每条主要意见必须可解决**：说明什么分析或修改能满足该意见
- 每位审稿人**至少 3 条主要意见**，否则说明为何认为不存在
- 不打分数，不鼓励，不做"优点三明治"

### 编辑综合与评分

七维 0–5 分评分（必须逐维打分，不能含糊）：

| 维度 | 0–1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **贡献** | 无新颖性 | 边际创新 | 明确贡献 | 重要新发现 | 改变领域 |
| **识别** | 设计残缺 | 识别薄弱 | 合理但不完美 | 可信设计 | 无可辩驳 |
| **数据** | 数据不足 | 有重大缺陷 | 数据尚可 | 丰富可信 | 理想数据 |
| **稳健性** | 无稳健性 | 最低限度 | 合理范围 | 全面 | 充分到位 |
| **量值** | 无解读 | 仅统计意义 | 有经济意义 | 完整基准 | 政策相关 |
| **阐述** | 难以理解 | 混乱 | 可读 | 清晰 | 典范 |
| **完整性** | 数据/代码缺失 | 部分缺失 | 基本完整 | 完整 | 可直接复现 |

**硬性校准锚点**（不得调高）：
- 任何维度 0–1 → 拒稿
- 识别 ≤ 2 → 拒稿；没有稳健性检验能补救残缺设计
- Major R&R 要求：贡献 ≥ 3，识别 ≥ 3，无维度 < 2

```
评分: 贡献=X 识别=X 数据=X 稳健性=X 量值=X 阐述=X 完整性=X
结论: <桌面拒稿 | 审后拒稿 | 大修 | 小修>
编辑信: ...
修改清单:
  [阻断] → 路由到 <causal-inference | aer-paper-sections | citation-integrity>
  [主要] → 路由到 ...
  [次要] → 路由到 ...
```

### 循环直到放行

```
aer-consistency 7项全 PASS
  → pre-submission-review（Stage 2）
      → 结论 = 桌面拒稿/审后拒稿？
          → 按修改清单路由修改
          → 重新运行 aer-consistency → 重新运行模拟审稿（全新报告，不重评旧报告）
      → 连续两轮 major R&R 且无阻断意见
          → submission-readiness（最终格式和提交检查）
```

**警告**：重新运行必须生成全新的三份报告，不是重评上一轮。方差不等于进步。

---

## 常见失败模式

- 审稿人发现正文"4.2%"但表格是"0.042"（单位混淆）
- 摘要引用了列 3 系数，引言引用了列 5 系数（规格不一致）
- 结论说"驱动了增长"，结果节说"与增长相关"（因果语言升级）
- 模拟审稿发现没有一条主要意见，说明模拟过于宽松——重跑并调高审稿人攻击性
