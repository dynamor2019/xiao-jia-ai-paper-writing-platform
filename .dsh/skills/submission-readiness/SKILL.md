# Submission Readiness

## 期刊优先

先加载用户选择的 `journal-*` skill，再打开该刊官方作者指南核对当前要求；skill 中的影响因子、字数、模板、费用和政策只作缓存，不能代替在线核验。候选与检查不得加入 MDPI 期刊。

---

## AEA 期刊路由决策（投稿前必做）

若目标期刊在 AEA 家族内，先运行此决策树，**然后**再做格式检查：

```
贡献句够短、结果够单一，符合 AER:Insights 公式？
  ├─ 是 → 跨子领域兴趣广泛？
  │   ├─ 是 → AER: Insights（≤7000词 - 每个图表×200词）
  │   └─ 否 → AEJ: Applied / Policy / Macro / Micro（按子领域）
  └─ 否 → 跨子领域兴趣广泛（非本领域经济学家也关心）？
      ├─ 是 → AER（全文 ≤40 排版页）
      └─ 否 → AEJ 家族或顶级领域期刊
```

**常见路由错误**：
- 把长文压缩到 Insights 格式：Insights 要求**简洁设计**，不是截短的 AER
- AEJ 作为 AER 拒稿后的备选：两者接受率逻辑不同，不是层级关系
- 向 AER 投稿而贡献只在单一子领域：明确的跨子领域兴趣是 AER 的显式门槛

## AER / AER:Insights 格式硬性约束

（超出任一约束自动退回，不进入审稿）

| 项目 | AER | AER: Insights |
|---|---|---|
| 摘要 | **≤ 100 词**（超出退回） | **≤ 100 词** |
| 正文长度 | ~40 排版页（含图表、参考文献、页内附录） | 7000词 − 每个图表×200词；≤5图表剩 6000词 |
| 正文字数计算范围 | 正文 + 脚注 + 页内附录；不含封面、摘要、参考文献、补充附录 | 同左 |
| 无 Introduction 标题 | **强制**（直接正文，无节标题） | 同 |
| 节编号 | 罗马数字（I. II. III.）；子节大写字母（A. B. C.）| 同 |
| 图表格式 | booktabs（无竖线），标题上方（表）/ 下方（图） | 同 |
| 参考文献格式 | AER 格式（author-year inline，按姓氏排列） | 同 |
| 文件格式 | 单一 PDF（正文+参考文献+图表+页内附录） | 同 |
| 补充材料 | 独立 PDF，标注为 "Supplemental Appendix" | 同 |

## 投稿包检查清单

### 稿件内容

- [ ] 范围、文章类型、创新点与期刊匹配
- [ ] 摘要词数精确计数（不是目测），符合上限
- [ ] 引言无 "Introduction" 标题（AEA 家族）
- [ ] 所有节标题、图表编号严格递增、无跳号
- [ ] 图表格式符合目标期刊规范（booktabs / 无竖线）
- [ ] 每张图有 notes 块：估计量、CI 类型、样本、N
- [ ] 每张表 notes 包含：SE 聚类层级、样本定义、显著性星号约定
- [ ] 正文每个量值的单位与期刊约定一致（百分点 vs 百分比）
- [ ] 结论节无在正文未出现过的新结果或新引用

### 引用与参考文献

- [ ] `citation-integrity` 台账全部 yes（存在性/字段/主张/状态/版本）
- [ ] `\cite{}` 与 `.bib` 条目双向匹配，LaTeX 编译零 unresolved 警告
- [ ] 已发表论文引用发表版（非工作论文版）
- [ ] 无撤稿或有重大更正的论文被引

### 作者信息与声明

- [ ] 作者贡献（CRediT 格式）完整
- [ ] 资金来源与项目编号填写
- [ ] 利益冲突声明（无利益冲突时也须明确声明"无"）
- [ ] 数据可用性声明（数据来源、访问方式、已存档位置或受限原因）
- [ ] 代码可用性声明（仓库链接或"应请求提供"）
- [ ] 生成式 AI 使用声明（若使用，说明具体工具和用途；不使用也须在需要时声明）
- [ ] 伦理审批（如涉及人类被试：机构/编号/知情同意/匿名）

### 复现包（AEA 标准）

- [ ] README 存在且为 PDF 格式（AEA 要求的最终存档格式）
- [ ] README 包含七节：总览、数据可用性声明、数据集列表、计算需求、程序说明、复现步骤、图表-脚本映射表
- [ ] master 脚本从干净环境端到端运行无报错
- [ ] 所有路径为相对路径（无硬编码绝对路径）
- [ ] 随机种子已设定
- [ ] 所有软件包版本已记录（Stata: `ssc install` + `which`；R: `renv`；Python: `requirements.txt` 精确版本）
- [ ] 图表-脚本映射表：每个发表图/表 → 生成脚本 → 输出文件
- [ ] 受限数据：有获取说明 + 公开代码 + 可选合成数据

### 文件包

- [ ] 主 PDF 可正常打开，公式为真实公式（非图片），字体嵌入
- [ ] 没有修订痕迹、注释、草稿水印
- [ ] 若提供 DOCX：公式可编辑，非截图公式
- [ ] 匿名审稿要求（若有）：PDF 元数据已清除，作者信息未露出
- [ ] 补充附录标注为独立文件

### Cover Letter（仅需要时）

AER **不要求** cover letter；**只有以下情况才写**（控制在 ≤200 词）：
- 与编委成员的利益冲突（须点名）
- 受限数据的特殊复现安排
- 与本刊相关的上一轮投稿历史

**禁止**在 cover letter 中推销贡献、列出研讨会、对潜在审稿人提出要求。

## 输出

生成 `submission/submission-manifest.md`，每项标记：
- `PASS`：已核验，证据位置
- `BLOCKED`：问题描述 + 修复指引
- `N/A`：不适用于本稿

**任何 BLOCKED 项存在 → 不得声称"投稿就绪"**。

## 提交后时间预期（AEA 家族）

| 期刊 | 首次决定中位时间 | 桌面拒稿 |
|---|---|---|
| AER | 8–12 周 | 通常 2–4 周内 |
| AER: Insights | 较快 | 通常更快 |
| AEJ 家族 | 因子领域而异 | — |

收到桌面拒稿后：12 周内不应主动询问编辑办公室状态。
